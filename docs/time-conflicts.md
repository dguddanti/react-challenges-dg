Prevent users from selecting a course that has a time conflict with any course they’ve already selected. Two courses conflict if they are in the same term, meet on at least one common day, and have overlapping times. Meeting strings look like MWF 9:00-9:50 or TuTh 14:00-15:20, with days from M, Tu, W, Th, F, Sa, Su in any combination. Courses with an empty meeting string never conflict, and a class ending at the same minute another starts is not a conflict.
Conflicting courses should be clearly marked as unselectable (for example, faded with an “×”) and should not respond to clicks. The display should update immediately as courses are selected and unselected, and selected courses must always remain unselectable so users can remove them. Keep the conflict logic out of the components, in a separate utility module that is broken into small, readable functions.
